# دائرة (Daira) — تطبيق تواصل خاص للأصدقاء فقط

نسخة أساسية (Jetpack Compose) بواجهة وتنقل فعلي بين 4 شاشات، وبيانات وهمية (Dummy Data) للعرض.

## كيف تشغّله
1. حمّل **Android Studio** (أحدث إصدار مستقر).
2. افتح المجلد `Daira` كاملًا من قائمة *Open* — الاستوديو سيولّد ملفات الـ Gradle Wrapper المفقودة تلقائيًا أول مرة.
3. اضغط ▶ Run على جهاز حقيقي أو محاكي (Emulator).

## قرارات تقنية مهمة
- **الحد الأدنى للإصدار (minSdk 21 / Android 5.0):** يغطي عمليًا كل الأجهزة النشطة حاليًا. "دعم كل الإصدارات" حرفيًا (حتى Android 1.0) غير عملي وغير آمن تقنيًا، لذلك اخترنا حدًا واقعيًا وشائعًا.
- **المنشورات لا تزال وهمية مؤقتًا** (بالاتفاق — مؤجلة لمرحلة لاحقة). موجودة في `data/DummyData.kt`.

## قاعدة البيانات (Room) — مفعّلة الآن ✅
الأعضاء ورمز الدعوة والدردشة أصبحت **تخزينًا فعليًا حقيقيًا** على الجهاز (SQLite عبر Room)، تبقى محفوظة حتى بعد إغلاق التطبيق أو إعادة تشغيل الجهاز.

بنية الطبقة:
- `data/db/` — الكيانات (Entities) والـ DAOs وفئة `DairaDatabase`
- `data/DairaRepository.kt` — منطق العمل (مثل: إبطال الرمز القديم تلقائيًا عند توليد رمز جديد، ضمن Transaction واحدة)
- `viewmodel/DairaViewModel.kt` — يربط الشاشات بالبيانات الحقيقية عبر `StateFlow`

**بيانات أولية (Seed):** أول مرة يفتح فيها المستخدم التطبيق، تُزرع تلقائيًا بيانات تجريبية (٤ أعضاء، ٤ محادثات، رمز دعوة أول) — بعدها كل شي حقيقي ومستمر.

**تجربة سريعة:** اضغط على أي محادثة في شاشة "الدردشة" لإرسال رسالة تجريبية — لاحظ إنها تبقى محفوظة حتى بعد إغلاق التطبيق وإعادة فتحه. وجرّب زر "رمز جديد" في شاشة "دائرتك" — الرمز القديم يُبطَل فورًا.

## تسجيل الدخول (Firebase Authentication) — مفعّل الآن ✅
التطبيق صار يتطلب حساب حقيقي بالبريد الإلكتروني وكلمة مرور (عبر Firebase)، بدل الدخول المباشر بدون تحقق.

- `viewmodel/AuthViewModel.kt` — يدير حالة الدخول (تسجيل / دخول / خطأ / تسجيل خروج) عبر Firebase Auth
- `ui/screens/LoginScreen.kt` — شاشة موحّدة لتسجيل الدخول وإنشاء حساب جديد
- `MainActivity.kt` — يعرض شاشة الدخول تلقائيًا لو المستخدم غير مسجَّل، ويعرض التطبيق الكامل بعد نجاح الدخول
- زر **تسجيل الخروج** موجود بشاشة "حسابك"

**ملف `app/google-services.json` مطلوب:** بدونه البناء يفشل. تأكد إنه مرفوع بمجلد `app/` بالريبو (مو بالجذر الرئيسي).

**ملاحظة مهمة:** الدائرة والأعضاء ورمز الدعوة والدردشة **لسا محليين فقط** (Room) — يعني كل جهاز له بياناته الخاصة، بغض النظر إن تسجيل الدخول صار حقيقيًا ومشتركًا بين الأجهزة. الخطوة الجاية المنطقية هي نقل هذي البيانات لقاعدة بيانات Firebase (Firestore) بدل Room المحلية، عشان تتشارك فعليًا بين أجهزة الأصدقاء.

## الخطوة التالية المقترحة
- بناء شاشة محادثة تفصيلية حقيقية (فتح محادثة معيّنة وكتابة رسالة بنفسك بدل الرسالة التجريبية الثابتة).
- تفعيل المنشورات الحقيقية بنفس أسلوب Room.
- ربط رمز الدعوة فعليًا بعملية "انضمام" حقيقية من جهاز صديق آخر (يتطلب خادم/Backend لاحقًا، بما إن كل جهاز حاليًا له قاعدة بياناته المحلية الخاصة فقط).
